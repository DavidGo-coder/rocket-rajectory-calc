# 🚀 Rocket Trajectory Calc

Highly optimised real-time physics simulation engine built with **GO** for mathematical computations and **Python** for 3D data visualization.

## 🛠️ Tech Stack & Archiecture
- **Computational Core:** Go (Golang) - lightning-fast physics loops, high-perfomance buffered I/O using `bufio`, and custom CSV telemetry exporters.
- **Data Analytics Engine:** Python (Pandas, Matplotlib) - automated folder path resolution via `path/filepath` equivalent and full 3D trajectory rendering.
